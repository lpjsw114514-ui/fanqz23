## 🚀 使用方法

1. 下载或克隆本项目所有文件到同一目录。
2. 用浏览器打开 `index.html` 即可使用。
3. 手机端可将文件保存到本地，通过文件管理器打开。

> **提示**：由于数据保存在浏览器本地，清除浏览器数据或更换设备会导致记录丢失。建议定期备份重要数据。

---

## 🛠️ 技术说明

- 纯 HTML + CSS + JavaScript，无任何框架与依赖。
- 使用 `localStorage` 持久化存储，键名如下：
  - `pomodoro_nickname`：昵称
  - `pomodoro_records`：专注记录
  - `pomodoro_total_minutes`：累计专注分钟数
  - `pomodoro_work_rest_settings`：工作/休息设置
  - `pomodoro_auto_cycle`：循环开关状态
